# Học smart contract — ngày 26/10

## Quy trình
1. Viết contract Solidity trong file .sol.
2. Compile thành ABI và bytecode.
3. Test hành vi trên blockchain local.
4. Deploy lên Fuji bằng ví testnet.
5. Lưu contract address, ABI và deployment transaction.
6. Kiểm tra trên explorer.
